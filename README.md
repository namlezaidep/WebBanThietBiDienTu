# WebBanThietBiDienTu
Website bán thiết bị điện tử


## Giới thiệu
Project website bán thiết bị điện tử môn Công Nghệ Phần Mềm.

## Công nghệ sử dụng
- ASP.NET Core MVC
- SQL Server
- Bootstrap

## Chức năng dự kiến
- Quản lý sản phẩm
- Giỏ hàng
- Đặt hàng
- Quản lý đơn hàng
